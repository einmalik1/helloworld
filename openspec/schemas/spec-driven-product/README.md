# spec-driven-product

Project schema based on a **copy** of community `spec-driven-with-adr`, extended for Hello World:

| Artifact | Role |
|---|---|
| proposal → specs → design | as stock / community |
| adr | change-local `adr.md`; durable ADRs in `openspec/decisions/` |
| data-model | optional; durable SQL/ERD under `openspec/data-model/` |
| design-system | optional; durable UI language under `openspec/design-system/` |
| tasks → apply | implementation |

Delivery/process docs stay under `spark/` (not this schema).
